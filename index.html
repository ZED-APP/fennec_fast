مقدمة

نحن في الفنك السريع للحساب الذهني نحترم خصوصية المستخدمين ونلتزم بحماية بياناتهم الشخصية. توضّح سياسة الخصوصية هذه كيفية جمع واستخدام وحماية المعلومات عند استخدام التطبيق.

المعلومات التي نقوم بجمعها

  • الاسم أو اسم المستخدم
  • البريد الإلكتروني
  • نوع الحساب (مدرب / متدرب)
❗ لا نقوم بجمع أو تخزين صور المستخدمين.

بيانات التمارين

  • إعدادات التمارين التي يرسلها المدرب
  • نتائج التمارين (السرعة، الدقة، عدد التمارين)

ما لا نقوم بجمعه

  • الصور
  • المحادثات أو الرسائل
  • الموقع الجغرافي
  • البيانات الحساسة

التخزين والحماية

يتم تخزين البيانات باستخدام Firebase Realtime Database و/أو Firestore مع تطبيق قواعد أمان Firebase.

Introduction

At Fast Mental Math, we respect users’ privacy and are committed to protecting personal data. This Privacy Policy explains how information is collected and used.

Information We Collect

  • Name or username
  • Email address
  • Account type (Trainer / Trainee)
❗ We do not collect or store user photos.

Training Data

  • Training settings sent by trainers
  • Training results (speed, accuracy, exercises)

Information We Do Not Collect

  • Photos
  • Chat messages
  • Contacts
  • Location data
  • Sensitive personal data

Data Storage & Security

Data is stored using Firebase Realtime Database and/or Firestore and protected with Firebase Security Rules.
